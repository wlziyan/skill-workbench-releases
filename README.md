# Skill 桌面工作台 · 发布区

这里只放 **Windows 安装包（zip）**，源码在工作台的私有仓库里，不在此处。

## 下载

到 [Releases](../../releases) 页面下载最新版本，例如：

- `SkillWorkbench-v1.6.8-win64.zip`（约 17 MB）

## 使用

1. 解压 zip（会得到 `Skill工作台/` 目录）
2. 双击 `Skill工作台.exe`
3. 不需要安装 Python，数据在 `%APPDATA%\WorkBuddy\data`

## 说明

- 仅支持 Windows x64
- 只绑定 `127.0.0.1:8851`，不对局域网开放
- 版本功能见各 Release 的说明
